# Portaria • Pátio • Expedição — PWA

Pacote preparado para publicação no GitHub Pages.

## Publicação
1. Envie todos os arquivos desta pasta para um repositório GitHub.
2. Em **Settings → Pages**, selecione a branch e a pasta `/root`.
3. Abra o endereço publicado pelo GitHub Pages.
4. No Android/Chrome, use **Adicionar à tela inicial** para instalar como PWA.

## Arquivos
- `index.html` — aplicação original enviada, preparada como página principal.
- `manifest.webmanifest` — configuração de instalação do PWA.
- `sw.js` — cache básico/offline do app shell.
- `icons/` — ícones do aplicativo.
